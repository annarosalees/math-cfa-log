# math-cfa-log

CFA Level 1 の学習に入る前に、中学〜高校レベルの数学を基礎から立て直すための学習ログです。

## 目的

- CFAの数式（TVM、統計等）を見たときに「数式部分で思考が止まらない」状態を作ること
- 学習過程を記録し、キャリアポートフォリオとしても機能させること

※ フェーズ0〜3は「一般的な数学の土台」。フェーズ4〜5では、CFA Level I の Quant で山場になる
推定・仮説検定・相関・回帰を、日本語の本で先に一周しておく（2026-10-22 方針変更）。
英語のCFA教材では「用語を対応づけるだけ」で済む状態を作るのが目的で、範囲はCFA Level I に出る部分に絞る。

## ロードマップ（全36 issue）

各issueの型は共通：①概念の説明（数式より先に言葉で理解）→②軽い練習問題2〜3問（できれば手計算）→③ログに1〜2行記録。

### フェーズ0：土台固め（issue #1〜#9）
正負の数、分数、小数⇔分数・割合、%計算、平方根、指数の基本ルール、文字式・簡単な方程式、関数とは何か、数学記号（√, ln, ≈）。

### フェーズ1：指数・対数（issue #10〜#13）
指数関数の基本、複利計算（TVMの正体）、対数の基本、対数の性質とTVM公式内での使われ方。

### フェーズ2：等比数列（issue #14〜#17）
数列の基本、等比数列の一般項、等比数列の和の公式、年金（Annuity）計算との対応づけ。

**→ #1〜#17がここまで。日本一時帰国（10月半ば）までの目標ライン**

### フェーズ3：基礎統計（issue #18〜#25）
添字とΣ記法、平均・中央値・最頻値、分散・標準偏差、場合の数、確率の基本、確率分布の考え方、正規分布の基本、Zスコアと標準正規分布表の使い方。

**→ 当初は帰国後の予定だったが、前倒しで進行（2026-10 完了見込み）**

### フェーズ4：統計の全体像（issue #27〜#32）
教材：『文系でもわかるビジネス統計入門』（内田学ほか）。第3〜9章を使う。
変動係数・標本調査と標本分布、区間推定（中心極限定理）、t分布、統計的検定の入口、相関係数と共分散、回帰分析。
第1〜2章は #19〜#25 と重なるため省略（1-4 変動係数のみ #27 で扱う）。

### フェーズ5：仮説検定を固める（issue #33〜#37）
教材：『入門統計学 −検定から多変量解析・実験計画法まで−』（栗原伸一）。CFAに必要な章だけを使う。
仮説検定の考え方（p値・第1種/第2種の誤り）、平均と平均の差の検定、分散の検定と独立性の検定（χ²・F）、
相関・回帰の検定（決定係数・分散分析表）、総仕上げ（CFA Quantの目次との照合と英語の対訳）。

**→ #27〜#37は日本帰国（2027年1月中旬）までに完了させる。ペースは平日1時間。年末年始は休み、帰国前の1週間は予備**

### 後回し（CFA Level I の後）
多変量解析（重回帰の詳細・主成分分析など）、実験計画法、数量化I類、コンジョイント分析。
CFA Level I の範囲外のため。データ分析の目標（重点目標3）やCFA Level II で必要になった時点で再開する。
