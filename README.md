# math-cfa-log

CFA Level 1 の学習に入る前に、中学〜高校レベルの数学を基礎から立て直すための学習ログです。

## 目的

- CFAの数式（TVM、統計等）を見たときに「数式部分で思考が止まらない」状態を作ること
- 学習過程を記録し、キャリアポートフォリオとしても機能させること

※ CFA固有の統計トピック（共分散・仮説検定・回帰分析等）はここでは扱いません。
それらはCFA教材本体で学ぶため、対象は「一般的な数学の土台」のみです。

## ロードマップ（全25 issue）

各issueの型は共通：①概念の説明（数式より先に言葉で理解）→②軽い練習問題2〜3問（できれば手計算）→③ログに1〜2行記録。

### フェーズ0：土台固め（issue #1〜#9）
正負の数、分数、小数⇔分数・割合、%計算、平方根、指数の基本ルール、文字式・簡単な方程式、関数とは何か、数学記号（√, ln, ≈）。

### フェーズ1：指数・対数（issue #10〜#13）
指数関数の基本、複利計算（TVMの正体）、対数の基本、対数の性質とTVM公式内での使われ方。

### フェーズ2：等比数列（issue #14〜#17）
数列の基本、等比数列の一般項、等比数列の和の公式、年金（Annuity）計算との対応づけ。

**→ #1〜#17がここまで。日本一時帰国（10月半ば）までの目標ライン**

### フェーズ3：基礎統計（issue #18〜#25）
添字とΣ記法、平均・中央値・最頻値、分散・標準偏差、場合の数、確率の基本、確率分布の考え方、正規分布の基本、Zスコアと標準正規分布表の使い方。

**→ #18〜#25は帰国後、CFA本格着手までの期間で進める**

## フォルダ構成

- [`cfa/log.md`](cfa/log.md) — CFA本格着手後の学習ログ（同様の形式）
