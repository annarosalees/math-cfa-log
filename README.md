# math-cfa-log

CFA Level 1 の学習に入る前に、中学〜高校レベルの数学を基礎から立て直すための学習ログです。

## 目的

- CFAの数式（TVM、統計等）を見たときに「数式部分で思考が止まらない」状態を作ること
- 学習過程を記録し、キャリアポートフォリオとしても機能させること

※ フェーズ0〜3は「一般的な数学の土台」。フェーズ4では、CFA Level I の Quant で山場になる
推定・仮説検定・相関・回帰を、日本語の本2冊で先に学んでおく（2026-10-22 方針変更）。
CFA Level I に関係する章は、2冊で内容が重なっていても省略せずに両方やる（くり返しで定着させるため）。
フェーズ4.5では、統計の本に出てこない金融特有の数学と金融電卓を、帰国後・CFA本体の前に学ぶ。
CFA Level I の範囲外の章は、フェーズ5としてCFAの後に回す。

## ロードマップ（全90 issue）

各issueの型は共通：①概念の説明（数式より先に言葉で理解）→②軽い練習問題2〜3問（できれば手計算）→③ログに1〜2行記録。

### フェーズ0：土台固め（issue #1〜#9）
正負の数、分数、小数⇔分数・割合、%計算、平方根、指数の基本ルール、文字式・簡単な方程式、関数とは何か、数学記号（√, ln, ≈）。

### フェーズ1：指数・対数（issue #10〜#13）
指数関数の基本、複利計算（TVMの正体）、対数の基本、対数の性質とTVM公式内での使われ方。

### フェーズ2：等比数列（issue #14〜#17）
数列の基本、等比数列の一般項、等比数列の和の公式、年金（Annuity）計算との対応づけ。

**→ #1〜#17がここまで。日本一時帰国（10月半ば）までの目標ライン**

### フェーズ3：基礎統計（issue #18〜#25）
添字とΣ記法、平均・中央値・最頻値、分散・標準偏差、場合の数、確率の基本、確率分布の考え方、正規分布の基本、Zスコアと標準正規分布表の使い方。

**→ 当初は帰国後の予定だったが、前倒しで進め、2026-10-23 に完了**

### フェーズ4：統計（CFA Level I 関係）（issue #27〜#73）
教材：『文系でもわかるビジネス統計入門』（内田学ほか）、『入門統計学 −検定から多変量解析・実験計画法まで−』（栗原伸一）。

**進め方**
- 本ごとではなく、トピックごとに2冊を続けて読む（文系本でやさしく → 入門統計学で深く → 章末問題）
- 1 issue＝平日1時間で終わる量。CFAでの重要度が高いトピックから並べる
- 1回の流れ：①本を読む（例題は手で再現）→ ②Claudeに自分の言葉で説明し、質問・類題 → ③ログ
- 章末問題の回は、まずClaudeを使わずに自力で解き、間違えた問題だけClaudeと分析する
- 各issueに「Claudeへの聞き方」を記載。カレンダーの予定から issue を開いて始める

### フェーズ5：CFA Level I の後に再開（issue #74〜#79、ラベル `deferred`）

**再開するときにやること**（各issueの本文にもチェックリストとして記載）

- 再開する目的に合った Milestone に入れる（例：データ分析用、CFA Level II 用の Milestone を作る）。
  「CFA Level I 前段階：数学基礎固め」には入れない（CFA Level I の前の段階をまとめるための Milestone のため）
