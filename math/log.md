## 2026-09-12
- issue #1 正負の数の四則演算
- 気づき: 負×負＝正を単純暗記でなく規則性で見る視点を得た。また、掛け算・割り算は「ひとまとまりの数を作る操作」、足し算・引き算は「まとまり同士をつなげる操作」という捉え方が計算順序の理解に役立った

## 2026-09-12
- issue #2 分数の四則演算
- 気づき:
  1. 足し算・引き算には通分が必要 ― 単位が違うものは直接足せないから
  2. 掛け算には通分が不要 ― 掛けるたびに単位そのものが細かくなっていくから
  3. 割り算は逆数の掛け算に変換できる ― より小さい単位で数え直すと、その分だけ個数が増えるから
  4. 約分は通分の逆 ― 同じ量を、より大きな(粗い)単位で数え直す操作

  割り算が逆数の掛け算になるのは、通分してから分子同士を割る計算の中に、相手の分母を掛けるという操作(=ひっくり返した分数を掛けること)がすでに隠れているからだと理解できた。約分は通分の逆で、同じ量を粗い単位で数え直す操作

  5. 整数÷整数で表せる数（＝分数で表せる数）は、必ず「有限小数」か「循環小数」のどちらかになる
  6. √2は有限小数でも循環小数でもないため、分数にならない（無理数である）

## 2026-09-13
- issue #3 小数⇔分数の変換、割合の考え方
- 気づき:
  1. 分母が2と5だけの掛け算でできている分数は、必ず割り切れて小数が終わる ― 10=2×5なので、分母を10のべき乗にきれいに変形できるから。3など2・5以外の素因数が混ざると循環小数になる
  2. 割合の関係は「基準×割合＝比べる量」「割合＝比べる量/基準」の2つの式で表せる ― 割合は本質的に分数(比べる量÷基準)であり、%は基準を100とみなしたときの分数の言い換えにすぎない
  3. 割合の問題では「何を基準にしているか」を毎回言葉にして確認するのがわかりやすかった ― 特に「〇〇円は元の80%になっている」のような逆算(基準が未知)の問題で、基準を見誤らずに済んだ

## 2026-09-14
- issue #4 %計算の実践（割引・増減率など）
- 気づき:
  1. 割引・増加は「基準×(1±割合)」の1回の掛け算で計算できる ― 「20%引き」は「元の80%が残る」と言い換えられるから
  2. 割引・増加が連続する場合、2回目以降の%は常に直前の結果を新しい基準にする ― 基準そのものが変わるので、%を単純に足し算・引き算してはいけない（10%引き×2回≠20%引き）
  3. 逆算は「結果÷(1±割合)＝基準」― %の数字（12や20）をそのまま演算に使わず、必ず「1±0.◯◯」の倍率に変換してから使う
  4. 「+10%して-10%」は元に戻らない ― 2回目の%は基準が変わった後の数字にかかるため、下落を取り戻すには下落率より大きい%の上昇が必要（30%下落の回復には約42.9%の上昇が必要、など）
  5. 丸め誤差に注意 ― 途中で小数を切らず、最後にまとめて四捨五入する
  6. パーセンテージポイント(pp)と率としての%は別物 ― 「2%→3%」の変化は「1pp」でも「(3−2)÷2＝50%の増加」でもあり、どちらも正しいが意味が異なる。pp=単純な差、率としての%=変化量÷変化前の値という「変化量÷基準」の式そのもの

## 2026-09-15
- issue #5 平方根の基本
- 気づき:
  1. 平方根は「2乗の逆操作」― 2乗で符号が消えてしまうため、`x² = 9` の解は `x = ±3` と2つ出てくる。一方で `√` 記号自体は非負の値（主平方根）だけを返す約束事、という点が別物であることに注意が必要
  2. 整数÷整数で表せる数（＝分数で表せる数）は、必ず「有限小数」か「循環小数」のどちらかになる。√2は有限小数でも循環小数でもないため分数にならない（無理数）― `1²=1, 2²=4` の間に2があることから `1<√2<2` は分かるが、桁をどれだけ細かく挟み込んでいっても、ぴったり2乗して2になる場所には決してたどり着けない、という感覚で無理数を捉えられた
  3. `√a × √b = √ab` や `√(a/b) = √a/√b` は暗記でなく「両辺を2乗して同じ値になるか」で検証できる ― `√`は「2乗するとその数になる非負の数」なので、2乗した結果が一致すれば元の数も一致すると言える
  4. 有理化（分母の√を消す書き換え）は本質的な計算ではなく、分母を無理数のまま扱う手計算のしづらさを避け、答えの形を統一して比較しやすくするための作法

## 2026-09-16
- issue #6 指数の基本ルール（a^m×a^n、a^0、a^-n など）
- 気づき:
  1. `a^m × a^n = a^(m+n)` は新しいルールではなく、べき乗の定義（同じ数を掛けた回数）そのもの ― 掛け算をつなげると「掛けた回数」が単純に足し算されるだけ
  2. `a^0 = 1` は暗記ではなく、`a³ ÷ a³` を「指数のルール(指数を引く)」と「同じ数同士の割り算(=1)」の2通りで計算した結果が一致することから導ける
  3. 負の指数 `a^(-n) = 1/a^n` は「引き算」ではなく「逆数」を表しているだけ ― `a² ÷ a⁵` を分数にして約分すると `1/a³` になり、これが指数のルールでの `a^(-3)` と一致することから確認できた
  4. `(a^m)^n = a^(mn)` も同じ考え方の延長 ― `(a²)³ = a²×a²×a²` は結局 `a` を `2×3=6` 回掛けることになるので、指数同士は掛け算になる（①の指数の足し算とは区別して覚える）

## 2026-09-16
- issue #7 文字式・簡単な方程式（xを使った式の意味、xを求める）
- 気づき:
  1. `x` は「まだ分かっていない数」に名前をつけたもの ― 数字が全部揃っていない状況でも式として扱えるようにするための道具
  2. 方程式は「天秤の釣り合い」として捉えると理解しやすい ― 両辺に同じ操作（足す・引く・掛ける・割る）をしても釣り合い（等式）は崩れないから、そうやってxだけを片方に残していける
  3. 足し算↔引き算、掛け算↔割り算は互いに逆の操作 ― 元の式を作った操作を、逆向きに取り消していくことでxを求められる
  4. 操作が複数組み合わさった式（例: `2x+3=11`）は、最後に行われた操作から逆順に取り消す必要がある ― 先に掛け算部分を割ってしまうと、足し算部分も一緒に割られてしまい釣り合いが崩れる

## 2026-09-16
- issue #8 関数とは何か（xとyの対応関係、グラフの超基礎）
- 気づき:
  1. 「xを決めるとyが1つに決まる」という対応のルールのことを「関数」と呼ぶ ― 逆にxを決めてもyが1つに決まらない対応（身長→体重、月→読んだ本など）は関数ではない
  2. `y = x²`（正方形の1辺→面積）のように、計算式で表せるものは、xを決めればyが必ず1つに決まるので関数になる
  3. グラフは `(x, y)` の組み合わせを平面上の点として表したもの ― 表の各行が1つの点に対応する
  4. `y = 100x` のように、xが1増えるごとにyが一定量だけ変化する関数は、グラフにすると直線になる（この「xが1増えたときにyがいくつ増えるか」は後で「傾き」として扱う）

## 2026-09-16
- issue #9 数学記号に軽く触れる（√, ln, ≈）
- 気づき:
  1. `ln`（自然対数）は、対数の底を特別な数 `e`（約2.718）に固定したもの ― 「eを何乗したらその数になるか」を表す。`e¹=e` なので `ln(e)=1`、`e^0=1` なので `ln(1)=0`
  2. `≈`（近似的に等しい）は「厳密には違うが実用上は同じとみなす」という意味 ― πや√2のような無理数（issue #5参照）は有限の桁で正確に表せないため、`π ≈ 3.14` のように使う
  3. `ln(e^x) = x` が成り立つ ― `e^x` は「eをx乗した数」なので、「eを何乗したらこの数になるか」という`ln`の質問にそのままxが答えになる。`ln`と`e^`は互いに打ち消し合う逆の操作（√と2乗の関係と同じ）
  4. `log_a b`（`ln`も含む）は「`a^x = b` を成り立たせるxの値」そのものを表す1つの数 ― `y = a^x` の対応表を「xからyを求める」向きに読めば`a^x`、「yからxを求める」向きに逆に読めば`log_a`になる、という同じ表の行き帰りの関係。`e^(ln x) = x` も同様（逆に読んでから戻す）
  5. `ln(xy) = ln(x) + ln(y)` が成り立つ ― `x=e^p, y=e^q` と置くと `xy=e^p×e^q=e^(p+q)`（issue #6の指数法則）となり、両辺に`ln`を取ると `ln(xy)=p+q=ln(x)+ln(y)`。新しいルールではなく指数法則から導ける結果で、「掛け算を`ln`に通すと足し算に変わる」
  6. これでフェーズ0（issue #1〜#9、土台固め）が完了

## 2026-09-17
- issue #10 指数関数の基本（a^xのグラフと意味）
- 気づき:
  1. `y = a^x` はxが「掛けられる数」ではなく「指数（何回掛けるか）」の位置にある点が、一次関数や二次関数と根本的に違う ― xが1増えるとyは「一定量を足す」のではなく「一定の割合(a)倍する」ため、グラフは最初ゆるやかで右に行くほど急激に増える(または減る)独特のJ字カーブになる
  2. 底aが1より大きいと右肩上がり(指数関数的増加)、0<a<1だと右肩下がり(指数関数的減衰)になる ― これは`a^(-n)=1/a^n`（issue #6）の関係から、実は同じ現象を逆から見ているだけだと分かる。0<a<1の数は分数なので、`(1/a)^x = 1/a^x`となり、xが増えるほど分母が大きくなる＝値は小さくなる
  3. `a^(-n)=1/a^n`は「まず`a^n`を計算してから、その逆数(ひっくり返した数)を取る」という2段階の操作 ― `1/(1/4)`のような「分数で割る」計算でつまずいたが、「1の中に1/4はいくつ入っているか(=4個)」と考えると感覚的に理解できた
  4. どんなaでも`x=0`のとき必ず`y=1`になる（`a^0=1`、issue #6）― また`y`は絶対に0やマイナスにならず、x軸に触れずに近づいていくだけ(漸近線)
  5. 「1年ごとに1.05倍になる」預金のような複利の仕組みは`y=1.05^x`という指数関数そのもの ― 次のissue #11「複利計算」の`(1+r)^n`は、今回学んだ「底a」の考え方がそのまま当てはまる
