## 四則演算まわり

- **四則演算**: 足し算・引き算・掛け算・割り算の4つの計算の総称。
- **加法・減法・乗法・除法**: それぞれ足し算・引き算・掛け算・割り算の正式名称。
- **被加数・加数**: 足し算 `a + b` の `a`（被加数）と `b`（加数）。
- **被除数・除数**: 割り算 `a ÷ b` の `a`（被除数）と `b`（除数）。
- **商**: 割り算の結果（例: `10 ÷ 3` の商は `3`）。
- **余り**: 割り算で割り切れなかった残り（例: `10 ÷ 3` の余りは `1`）。
- **分数**: `分子/分母` の形で表される数。例: `3/4`。
- **分子・分母**: 分数の上の数（分子）と下の数（分母）。`3/4` なら分子は`3`、分母は`4`。
- **通分**: 分母の異なる分数を、同じ分母に揃える操作。足し算・引き算の前に必要。
- **約分**: 分子と分母を同じ数で割って、より簡単な形にする操作。
- **逆数**: ある数を掛けると1になる数。`a` の逆数は `1/a`（例: `2` の逆数は `1/2`）。割り算は逆数の掛け算に変換できる。

## 数の性質

- **素数**: 1とその数自身以外に約数を持たない、2以上の整数（例: 2, 3, 5, 7, 11）。
- **合成数**: 素数ではない2以上の整数（例: 4, 6, 8, 9）。
- **公約数・公倍数**: 2つ以上の数に共通する約数（公約数）・倍数（公倍数）。
- **最大公約数（GCD）**: 公約数の中で最大のもの。
- **最小公倍数（LCM）**: 公倍数の中で最小のもの。
- **整数・自然数・有理数・無理数**:
  - 自然数: 1, 2, 3, ... のような正の整数（0を含むかは文脈による）。
  - 整数: 自然数に0と負の数を加えたもの。
  - 有理数: 分数（整数/整数）で表せる数。
  - 無理数: 分数で表せない数（例: √2, π）。
- **有限小数**: 小数点以下がどこかできっちり終わる小数（例: `0.5`、`0.25`、`0.125`）。
- **循環小数**: 小数点以下で同じ数字の並びが無限に繰り返される小数（例: `1/3 = 0.333...`、`1/7 = 0.142857142857...`）。有理数（分数）は必ず有限小数か循環小数のどちらかになる。

## べき乗・指数・対数

- **べき乗**: 同じ数を何回か掛け合わせること。`2³ = 2×2×2 = 8`。
- **指数**: べき乗の右上に小さく書く数。`2³` の `3` が指数。
- **底（てい）**: べき乗の元になる数。`2³` の `2` が底。対数 `log_a x` の `a` も底と呼ぶ。
- **平方・立方**: 2乗（平方）・3乗（立方）のこと。
- **平方根**: 2乗すると元の数になる数。`√9 = 3`（`3² = 9` だから）。
- **主平方根**: `√` 記号が指す非負の平方根。`x² = 9` の解は `x = ±3` だが、`√9` は `3` のみを指す（この2つは別物なので混同注意）。
- **累乗根**: n乗すると元の数になる数の一般形（平方根はn=2の場合）。
- **有理化**: 分数の分母に√がある形を、分子・分母に同じ数を掛けて分母から√を消す書き換え（例: `1/√2 = √2/2`）。値そのものは変わらず、手計算のしやすさや表記の統一のための作法。
- **指数関数**: `f(x) = a^x` の形の関数。複利計算などで登場する。
- **対数**: `a^x = b` のとき `x = log_a b` と表す。「底aを何乗したらbになるか」を表す数。
- **真数**: 対数 `log_a b` の `b` の部分（対数を取る対象の数）。
- **自然対数（ln）**: 底が `e`（ネイピア数、約2.718）の対数。`ln x = log_e x`。

## 数列

- **数列**: 一定の規則に従って並んだ数の列。
- **項**: 数列を構成する一つ一つの数。
- **一般項**: 数列のn番目の項を式で表したもの（`a_n` など）。
- **等差数列**: 隣り合う項の差が常に一定の数列（例: 1, 3, 5, 7, ...）。
- **等比数列**: 隣り合う項の比が常に一定の数列（例: 2, 4, 8, 16, ...）。
- **公差**: 等差数列における一定の差。
- **公比**: 等比数列における一定の比。
- **Σ記法（シグマ記法）**: 数列の和を表す記号。`Σ_{k=1}^{n} a_k` は `a_1 + a_2 + ... + a_n` を意味する。

## 基礎統計（先取り語彙）

- **平均・中央値・最頻値**:
  - 平均: 全データの合計をデータ数で割った値。
  - 中央値: データを大きさ順に並べたときの真ん中の値。
  - 最頻値: 最も出現回数が多い値。
- **分散**: データが平均からどれくらいばらついているかを表す指標（偏差の2乗の平均）。
- **標準偏差**: 分散の平方根。分散より元のデータと同じ単位で扱えるため直感的。
- **場合の数**: ある事象が起こりうるパターンの総数。
- **順列・組み合わせ**:
  - 順列: 順序を区別して選ぶ並べ方の数。
  - 組み合わせ: 順序を区別せずに選ぶ選び方の数。
- **確率**: ある事象が起こる割合（0〜1、または0%〜100%で表す）。
- **確率分布**: 起こりうる値とその確率の対応関係全体。
- **正規分布**: 平均を中心に左右対称な釣鐘型の確率分布。自然現象や統計でよく現れる。
- **Zスコア**: あるデータが平均から標準偏差何個分離れているかを表す標準化された値。
